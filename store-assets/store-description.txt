Stop blindly accepting cookies. Consent Pilot automatically rejects all non-essential cookies on GDPR cookie banners — properly, not by hiding them.

WHAT IT DOES
Unlike other extensions that hide cookie banners (which often means silently accepting everything), Consent Pilot actually clicks "Reject All" for you. If there's no reject button, it opens the preferences panel, unchecks all optional categories, and saves.

HOW IT WORKS
Consent Pilot uses a 4-layer approach:

1. TCF API — Uses the IAB standard consent API (~40% of EU sites)
2. CMP-specific handlers — Knows exactly how to reject cookies on OneTrust, Cookiebot, Didomi, TrustArc, Quantcast, Usercentrics, Civic, Klaro, Borlabs, and OREJIME
3. Smart heuristics — Multi-language button detection (EN, NL, DE, FR, IT, ES, PT, PL) with dark pattern awareness
4. Local AI fallback — Optional on-device AI model for unknown banners (runs locally, no data sent anywhere)
