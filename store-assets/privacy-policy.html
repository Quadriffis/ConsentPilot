Consent Pilot — Privacy Policy

Last updated: February 2026

Summary

Consent Pilot does not collect, store, or transmit any personal data. Everything happens locally in your browser.

What data does Consent Pilot access?

  • Page content (DOM): The extension reads the HTML structure of cookie consent banners on the websites you visit. This is necessary to detect and interact with cookie banners. This data is processed locally and never sent anywhere.
  • Local storage: The extension stores your preferences (enabled/disabled, whitelisted sites) and anonymous statistics (number of banners handled) in Chrome's local storage on your device.

What data does Consent Pilot NOT access?

  • No browsing history
  • No personal information
  • No cookies (the extension rejects cookies — it does not read your existing ones)
  • No form data, passwords, or keystrokes

Does Consent Pilot send data to external servers?

No. All processing happens locally in your browser. The only network requests the extension makes are:

  • AI model download (optional): If the local AI fallback is activated, a machine learning model (~200MB) is downloaded once from Hugging Face (huggingface.co) and cached locally. No page content or personal data is sent during this download.

Permissions explained

  • storage: To save your settings and statistics locally
  • activeTab: To detect and interact with cookie banners on the current page
  • scripting: To inject the banner detection scripts into web pages
  • host_permissions (<all_urls>): Cookie banners can appear on any website, so the extension needs to run on all URLs
  • offscreen: To run the optional AI model in a background document

Third-party services

The optional AI feature uses:

  • Hugging Face Hub: To download the open-source SmolLM2-360M model. Subject to Hugging Face's privacy policy. Only the model files are downloaded — no user data is sent.
  • Transformers.js: An open-source library by Hugging Face that runs AI models locally in the browser. It does not transmit any data.

Changes to this policy

If we make changes, the updated policy will be published here. The extension itself will never collect personal data.
